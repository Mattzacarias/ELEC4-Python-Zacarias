## How to Run the Activities

1. Install [Python](https://www.python.org/downloads/).

2. Clone this repository:

```bash
git clone https://github.com/Mattzacarias/ELEC4-Python-Zacarias.git
```

3. Open the repository folder:

```bash
cd ELEC4-Python-Zacarias
```

4. Switch to the branch containing the activity you want to run.

For Set 1:

```bash
git switch set-1
```

For Set 2:

```bash
git switch set-2
```

5. Navigate to the activity folder and run its Python file.

**Set 1 commands:**

```bash
python set1/p1/p1_grade_calculator.py
python set1/p2/p2_main.py
python set1/p3/p3_record_manager.py
python set1/p4/p4_exceptions.py
```

**Set 2 commands:**

```bash
python set2/p5/p5_file_system.py
python set2/p6/p6_recursion.py
python set2/p7/p7_classes.py
python set2/p8/p8_inheritance.py
```

**Note:** Make sure to switch to the correct branch before running an activity. Some activities may require additional files, such as `students.txt`, which should remain in their respective activity folders.
